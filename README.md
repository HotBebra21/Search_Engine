# Поисковый движок (Search Engine)

Финальный проект по курсу «Разработчик C++» от Skillbox.

Проект представляет собой консольное приложение для полнотекстового поиска по набору текстовых документов на основе инвертированного индекса.

## Принцип работы

1. При запуске программа считывает конфигурационный файл `config.json`, в котором указаны название приложения, версия, лимит ответов `max_responses` и пути к текстовым файлам.
2. Тексты документов загружаются в память и индексируются классом `InvertedIndex`. Индексация каждого документа выполняется в отдельном потоке (`std::thread`).
3. Из файла `requests.json` считывается список поисковых запросов.
4. Класс `SearchServer` выполняет поиск по инвертированному индексу:
   - разбивает запрос на уникальные слова;
   - сортирует слова по частоте встречаемости;
   - находит подходящие документы и рассчитывает абсолютную и относительную релевантность;
   - сортирует результаты по убыванию релевантности (при равном ранге — по возрастанию `doc_id`).
5. Результаты поиска записываются в файл `answers.json`.

## Архитектура проекта

- **`ConverterJSON`** (`include/ConverterJSON.h`, `src/ConverterJSON.cpp`) — класс для работы с JSON-файлами (`config.json`, `requests.json`, `answers.json`) и чтения текстов документов.
- **`InvertedIndex`** (`include/InvertedIndex.h`, `src/InvertedIndex.cpp`) — класс для хранения базы документов и формирования частотного словаря слов в многопоточном режиме.
- **`SearchServer`** (`include/SearchServer.h`, `src/SearchServer.cpp`) — поисковый сервер, который выполняет ранжирование и расчет релевантности документов для каждого запроса.

## Структура файлов

- `CMakeLists.txt` — конфигурация сборки проекта CMake;
- `config.json` — конфигурация поискового движка и список файлов для поиска;
- `requests.json` — список поисковых запросов;
- `answers.json` — файл с результатами поиска;
- `include/` — заголовочные файлы классов и библиотека `nlohmann/json.hpp`;
- `src/` — исходные файлы `.cpp` классов и функции `main()`;
- `resources/` — текстовые файлы для индексации;
- `tests/` — модульные тесты Google Test.

## Сборка и запуск

Для сборки проекта требуется компилятор с поддержкой C++17 и CMake 3.14 или выше.

### Сборка через консоль

```bash
# 1. Генерация файлов сборки
cmake -B build

# 2. Компиляция проекта
cmake --build build

# 3. Запуск модульных тестов
./build/test_search_engine

# 4. Запуск поискового движка
./build/search_engine
```

Также проект можно открыть и запустить напрямую в IDE CLion или Visual Studio (открыв папку как проект CMake).

## Тестирование

Для проверки корректности работы классов реализованы модульные тесты на базе Google Test (`tests/test_search_engine.cpp`):
- `TestCaseInvertedIndex.TestBasic` — проверка базовой индексации документов;
- `TestCaseInvertedIndex.TestBasic2` — проверка подсчета частоты слов;
- `TestCaseInvertedIndex.TestInvertedIndexMissingWord` — обработка отсутствующих слов;
- `TestCaseSearchServer.TestSimple` — проверка базового ранжирования результатов;
- `TestCaseSearchServer.TestTop5` — проверка сортировки по релевантности и ограничения количества ответов `max_responses`.
